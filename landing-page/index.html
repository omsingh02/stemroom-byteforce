Make an account See the screens

Songs, projects and approvals.

Your portfolio

Add each song with its album and an optional mp3, wav or flac file of up to 25 MB. Every song shows whether it is pending, approved or rejected.

Projects with deadlines

Start a project with a title, a description and a deadline if you want one. Add another musician by email, and the project shows up for them straight away.

Admins decide what goes public

Admins approve or reject each song before it is shared. They manage accounts, roles and sign-ups from the same place.
